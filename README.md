Helper for the board game Next Station: London. Shuffles the 11 Station cards, flips them for you, and ends the round when the 5th pink Underground card is drawn. 4 rounds per game.

Keys: Enter/Space/tap draw, P past cards, R remaining cards (order hidden), F fullscreen, N new game. On touch screens the same actions are buttons under the Underground counter.
